# 開発計画書用フローチャートの紹介文

## 図1　システム全体

本システムは，Raspberry PiとEV3の2台で構成する．図1に示すように，カメラ画像の処理や数字の認識，行動の判断はすべてRaspberry Piが行い，EV3はモータの制御とセンサ値の取得を担当する．両者は有線LANのTCP通信で接続し，EV3がセンサ値を送信するたびに，Raspberry Piが走行と発射の指令を返す．指令が1秒間届かない場合，EV3はモータを停止する．処理の重い画像認識と機体の制御を分けることで，それぞれの役割を明確にする．

## 図2　全体の流れ

図2に，課題全体の処理の流れを示す．ロボットは狙う数字を1に設定して探索を始め，的を確定すると照準を合わせて，輪ゴム銃で1発発射する．発射後は狙う数字を1増やして次の的を探し，3の的に発射すると停止する．順番を間違えると失敗になるため，狙う数字を確定するまでは発射しない．また，弾は的と同じ3発であり，外すとすべての的を倒すことはできないため，的が倒れたかどうかの判定は行わず，的1枚につき1発だけ発射する．制限時間を過ぎた場合は，その時点で停止する．

## 図3　移動しながらの探索

図3に，図2の「移動しながら的を探す」処理の詳細を示す．ロボットは弧を描きながら前進し，カメラで数字を検出し続ける．狙う数字を確定すると停止し，照準の処理へ移る．順番外の数字を確定した場合は，誤って倒さないようにその的から離れる向きへ旋回する．また，超音波センサで前方が近すぎると判断した場合や，動けなくなった場合には向きを変え，長く同じ方向に進んだ場合には曲がる向きを変えることで，床の広い範囲を探索する．
